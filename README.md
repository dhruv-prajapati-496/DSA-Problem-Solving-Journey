## 📈 My Practice Approach

1. Understand the problem and identify its constraints.
2. Build an initial solution independently.
3. Test the solution against sample and edge cases.
4. Analyze time and space complexity.
5. Learn a more efficient technique when applicable.
6. Review mistakes and refine the implementation.
7. Commit completed solutions to GitHub.

My goal is to improve problem-solving ability, rather than simply increase the number of solved problems.

## 🚀 Running a Solution

Clone this repository:

```bash
git clone https://github.com/dhruv-prajapati-496/DSA-Problem-Solving-Journey.git
```

Navigate into the repository:

```bash
cd DSA-Problem-Solving-Journey
```

Compile any standalone C++ solution using G++:

```bash
g++ "Extra Questions For Practice/Arrays/squaresOfASortedArray.cpp" -o solution
```

Run it on Windows:

```powershell
.\solution.exe
```
